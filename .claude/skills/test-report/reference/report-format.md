# One-pager format

`/test-report` writes exactly this shape to `docs/reports/test-report.md`. Keep it to one screen —
it's for someone who will not open the test files. Numbers up top, names below, detail last.

```markdown
# Test Report — <Project> — <YYYY-MM-DD>

_Generated by /test-report from docs/requirements/registry.md + REQ-tagged tests + latest run._

## Headline

| Metric | Value |
|--------|-------|
| Requirement coverage | 18 / 22 active (82%) |
| Test pass-rate | 143 / 145 (98.6%) |
| New requirements this release | 4 |
| **Regressions caught** | **1** |
| Traceability gaps | 4 |

## Regressions (were passing, now failing) — ACT ON THESE

| REQ-ID | Requirement | Failing test |
|--------|-------------|--------------|
| REQ-ATT-02 | Attendance cannot be marked for a cancelled lecture | [REQ-ATT-02] blocks marking on a cancelled lecture |

## Coverage by module

| Module | Covered | Regressed | Gap | Coverage |
|--------|---------|-----------|-----|----------|
| ENQ | 3 | 0 | 0 | 100% |
| REG | 5 | 0 | 1 | 83% |
| SCH | 4 | 0 | 2 | 67% |
| ATT | 5 | 1 | 1 | 71% |

## Gaps (requirements with no test) — NEEDS /tdd

| REQ-ID | Requirement | Priority |
|--------|-------------|----------|
| REQ-SCH-05 | A 10-week schedule auto-repeats weekly | P0 |
| REQ-REG-04 | A student cannot register twice for the same batch | P1 |

## New this release

| REQ-ID | Requirement | Added |
|--------|-------------|-------|
| REQ-ENQ-03 | Only Admin/Teacher can create an enquiry | v1.2 |

## Orphan tags (test references an unknown/deprecated REQ-ID)

| Tag in test | Test title | Likely cause |
|-------------|------------|--------------|
| REQ-ENQ-09 | [REQ-ENQ-09] … | typo or removed requirement |
```

## Rules for filling it

- **Regressions section goes first after the headline** — it's the only part that demands action
  today; make it impossible to miss. Omit the section only if the count is genuinely zero.
- Every number in the headline must reconcile with the tables below it. If coverage says 18/22, the
  module table's covered column must sum to 18.
- If there are **no gaps / no regressions / no orphans**, keep the heading and write `None.` under
  it — an empty section is itself information (it says the join was actually run).
- Sort gaps by priority (P0 first) so the next `/tdd` target is obvious.
- Dates are the run date. Version/`Added` values come straight from the registry.
