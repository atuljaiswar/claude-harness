# Standing facts (semantic memory)

One fact per bullet — repo layout, conventions, ID/role mappings, current state. Keep current: on a
conflict, update the fact and note the change; don't leave two contradictory facts side by side.
The session-start hook surfaces these bullets as the index.

- <e.g. App root is `src/`; tests live in `tests/`.>
- <e.g. Auth: role model is exactly two roles — admin, member.>
- <e.g. Package manager is pnpm; never use npm install.>
